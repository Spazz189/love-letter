# Your Love Letter Website 💌

## What is inside
- index.html — the website
- style.css — the romantic design and flower animations
- script.js — page navigation, petals, and music button

## How to put it online
The easiest method is to use a free static website host such as GitHub Pages or another static hosting service.

1. Upload all three files together.
2. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
3. Publish the folder as a static website.
4. Open the website link on your phone to test it.
5. Send the link to your girlfriend.

## Music
The website does NOT contain or redistribute the copyrighted song.
The music button opens a YouTube search for the official Boyz II Men recording.

If you want a different official music page, open `script.js` and replace the value of `SONG_URL`.

## Editing the letter
Open `index.html` in any text editor and change the text between the `<p>...</p>` tags.

No images are required: the background, flowers, and animations are created by the website itself.
